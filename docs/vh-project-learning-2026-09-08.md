# Persistent projects and scheduling experience

## Behavior

Focus opportunities can now have a finite `projectMinutes` work target. Zero preserves the original recurring-activity behavior. Work actually executed accumulates in persistent project state across daily sessions, interruptions and missed windows. Reaching the target emits one project work-completion event and stops scheduling more sessions. This means planned effort was invested, not that an external result was achieved. A writing target does not establish that a good story was finished; preparing a job application does not establish a job offer.

Project effort uses actual executed milliseconds. Waiting, blocked time, sleep and conversation reservations contribute no project progress. Partial project work consumes a proportionate share of session energy/stress/hunger effects; it need not finish the entire session before having consequences. Final shortened sessions scale their effects with the remaining effort. These effects enter the existing shared life dynamics.

`learnFromOutcomes` is optional per opportunity. The kernel records each completed or missed opportunity window once. After three observations, experience contributes a bounded -6 to +6 scheduling priority adjustment; base priorities, availability, energy requirements, deadlines and the existing seeded variation still matter. Changed opportunity definitions get separate experience rather than inheriting an unrelated schedule's results. The system learns scheduling feasibility, not opinions about the player or a new personality.

Both fields are editable in Active Life → Daily opportunities. Project effort is displayed with its target. Existing opportunities remain recurring and learning-disabled unless authored otherwise. The Life Architect can propose these fields for new life profiles.

## Shared consequences

Project progress and scheduling experience persist in activity runtime and are available to foreground/compact conversation context and the background worker. Unfinished authored projects can supply grounded conversational motives. Project work completion enters the normal continuity, life-event and episode pathway, making it available to existing conversation and social agency. No separate invented social event is generated.

Progress persists if an opportunity is edited. Raising its work target permits further work; reducing the target does not undo historical work. The system retains up to 32 project records and 32 scheduling-experience records. More projects require a broader archive/editor design; it does not silently evict existing project progress to accept a new one.

## Verification

The alternate-history audit simulates seven days in the real activity kernel with the same seed, opportunities and availability. One history takes repeated conversational pauses; the other does not. Executed project effort and completion/missed-window experience diverge. Project work has energy consequences even in unfinished sessions. Repeating the interrupted history with serialization/normalization every minute yields identical state and cumulative effects.

Other checks cover bounded priority learning, once-only missed-window recording, exact target completion, no additional sessions after reaching the target, and browser save/reload of both new controls. Existing shared-host transaction checks pass. All generation calls in browser checks remain mocked.

## Limits

This is a project-effort and scheduling-learning milestone, not a complete emergent society. Projects currently use focus sessions and a work-time target, not arbitrary dependency graphs or externally evaluated quality. Learning adjusts selection priority; it does not yet invent a better time window, learn new skills, or negotiate another person's schedule. The week-long test is a kernel counterfactual, not a natural-language quality evaluation or a complete multi-person world simulation.

Reload the app and reopen the local launcher for the shared background runtime changes. No user saves or paid model calls were used for verification.
