# 16.7.0 Remaining Sanitized Commit Audit

## Method

Each remaining non-Legacy commit was compared against the current `16.7.0`
branch after the already-migrated provider, recovery, bridge and movement
changes. "Applies" means `git apply --check` can place the old patch; it does
not by itself mean that replaying it is architecturally safe.

## Summary

| Outcome | Commits | Meaning |
| --- | ---: | --- |
| Direct or near-direct port | 2 | Small isolated fixes with no meaningful 16.7 collision |
| Clean textual apply but deliberate redesign required | 3 | The patch fits, but its old assumptions conflict with the intended architecture or its content scope |
| Targeted adaptation | 5 | Preserve the feature while integrating with materially changed 16.7 surfaces |
| Fold into another port | 2 | No independent feature value |
| Already superseded in part | 1 | Only the still-missing part should move |

## What should move next

1. `6b94323` — direct faction-dedupe fix.
2. Cloud idle timeout half of `f893004` — small, independent resilience feature.
3. Narrative commerce (`ff34588` + `c335180`) — after a focused read of
   `rpg-mechanics.js` market dispatch.
4. Dossiers (`73c031e`) — a foundational, multi-commit port before later
   cognition and Sidecar adapters.
5. AI field completion (`b0e480c`) — reimplemented against the new inspector.
6. Consolidation settings (`ac918d5` + `b16dadd`) — as the base for the larger
   memory system.
7. World Agent proposals (`5be77a7`) — only after Sidecar protocol records and
   reducer boundaries are present.
8. Traversal nodes (`9721ecd`) — folded into the new traversal/vehicle design,
   not carried as a legacy transit-location system.
