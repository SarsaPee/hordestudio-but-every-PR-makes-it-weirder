# Horde Studio 15.7.0

## Interface overhaul

- Rebuilt Settings as a compact control center with clearer hierarchy and wider working space.
- Replaced the wall of provider forms with an expandable provider directory that opens the active provider and shows configured state at a glance.
- Separated MCP creative services from advanced ComfyUI and local-image workflows using progressive disclosure.
- Redesigned the Virtual Human social drawer header, tabs, relationship controls, autonomous-post controls and feed density.
- Fixed social header actions stacking because of an over-broad layout selector.
- Improved responsive behavior for narrow windows and reduced oversized cards, whitespace and image dominance.

## Reliability included in this build

- Corrected release metadata and cache identifiers so update checks recognize 15.7.0 accurately.
- Preserved provider independence: text, images and speech can continue using different services.
- Retained autonomous social scheduling, missed-window recovery, double-text delivery and GPTProto image recovery improvements.
