# Horde Studio 17.0.0

Horde Studio 17 introduces Video Adventures: a separate, story-first roleplay experience that turns persistent characters, canon and player decisions into short connected video scenes.

## Video Adventures

- Added a dedicated Video Adventure library, authoring studio, playable timelines and locally stored footage.
- Added a fast World Director that produces causal story beats, concise dialogue and three context-aware player choices instead of generic actions.
- Set `google/gemma-4-31b-it` as the default Director model while keeping an editable, provider-aware model picker and connection test.
- Added selectable visual presets, first-person or visible-player viewpoints, player reference images and fully authored recurring characters with identity references.
- Preserved story facts, relationships, unresolved threads, character identity and the previous clip's final frame between beats.
- Removed adventure-title metadata from renderer prompts and blocked cached dialogue that attempts to speak the interface title.

## Fal media and renderer resilience

- Added MiniMax H3 Max, Wan 3.0, Wan 3.0 Prime and LTX-2.3 Fast as selectable Fal video renderers.
- Added ordered primary, fallback and second-fallback selection for Video Adventures and Virtual Human clips.
- Existing adventures migrate to the resilient H3 Max → Wan 3.0 → LTX-2.3 Fast chain.
- Fallback attempts reuse the same Director plan, character reference and continuity frame instead of rewriting the story.
- Added durable background render jobs, progress reporting, cancellation, recovery after reload and bounded timeouts.
- Added renderer-aware duration, resolution and spending estimates, including LTX's supported duration mapping and the current H3 rates.
- Forwarded documented optional safety settings to supported H3 and Wan endpoints while clearly reporting mandatory hosted filtering that Horde Studio cannot override.

## Worlds and Virtual Humans

- Added Fal as an image provider for World locations, NPC portraits, map artwork and Virtual Human photos.
- Added Fal as a video provider for Virtual Human story clips with identity references and configurable fallbacks.
- Improved Virtual Human media portability by downloading completed Fal output through Horde Studio's local bridge.

## Interface and reliability

- Rebuilt the provider configuration layout so expanded cards remain readable and usable inside the Settings modal.
- Fixed recurring page and modal scrolling failures across Horde Studio.
- Added timeline rename and deletion controls and safer cleanup of locally stored clips.
- Repaired malformed Director JSON once automatically and surfaces a clear model-compatibility error if repair fails.
- Prevented generation overlays from replacing existing footage while the next scene renders.
- Added focused regression coverage for story choices, continuity, Fal policy errors, renderer fallback order, background jobs, media portability, settings, scrolling and portable packaging.

## Portable release

The portable archive includes the local launcher and bridge, Video Adventures runtime, built-in Virtual Humans, bundled runtime media, multiplayer relay source and guide, and the Policy Panic showcase World. Extract the ZIP and run the launcher for your platform; no installer is required.
