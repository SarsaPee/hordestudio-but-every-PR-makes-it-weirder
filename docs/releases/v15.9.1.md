# Horde Studio 15.9.1

## Critical memory and disk-write hotfix

- Fixed a Virtual Human agency loop that could rewrite the complete IndexedDB state every five seconds while the app was idle.
- Idle life and supporting-cast checks no longer become persistent changes merely because their polling timestamps advanced.
- Deterministic emotion and human-dynamics decay now remains an in-memory clock-derived cache until a real event or user action needs saving.
- Full-state saves are serialized and coalesced, preventing overlapping structured clones of media-heavy state from multiplying browser memory use.
- Protected media changes that occur during an active save so the trailing persistence pass cannot lose them.

This patch directly addresses the Firefox memory growth, NVMe write amplification and severe disk thrashing reported in GitHub issue #13. Existing characters, timelines, social feeds and embedded media remain compatible.

## Verification

- Added idle-agency regression coverage proving a five-second no-op poll does not dirty Virtual Human life state.
- Added persistence guards for coalescing and conditional simulation markers.
- Re-ran the complete Virtual Human engine audit and portable-build checks.
