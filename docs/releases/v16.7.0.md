# Horde Studio 16.7.0

Horde Studio 16.7 makes long-running roleplay meaningfully persistent and fixes the reliability issues reported in Faction editing and Virtual Human conversations.

## Persistent story memory

- Chat memory now belongs to a durable story continuity rather than a single disposable session.
- New sessions can continue the current continuity, fork it into an alternate timeline, or begin with fresh memory.
- Durable memory is stored as structured facts, relationships, current state, open threads, and important scenes with source provenance.
- Hybrid retrieval combines semantic similarity with local keyword matching, recency, importance, pinned canon, current state, and unresolved-thread signals.
- Recall uses a capped prompt budget, preserving recent dialogue while still bringing back the most relevant long-term context.
- Conflicting canon supersedes older records, while edits, rerolls, deletions, and chat clearing invalidate memories derived from removed messages.
- The Story Memory inspector can search, pin, edit, archive, or delete continuity records.
- Existing episodic memories migrate automatically, and stale embedding caches are refreshed safely when the provider or model changes.
- Backups now include story continuities and restore them with validation and schema repair.

## Reliability fixes

- Fixed Faction editor saves that could appear to work only after several attempts.
- Fixed Virtual Humans failing to reply in affected provider, availability, and timeline paths.
- Hardened persistence, settings migration, companion state, movement ledgers, and multiplayer mechanics against malformed or legacy data.
- Prevented memory consolidation races and fixed summaries being written to the wrong character or shared room.
- Added focused regression audits for Faction saves, Virtual Human replies, persistent story memory, persistence, settings, movement, and multiplayer behavior.

## Portable release

The portable archive includes the local launcher, built-in Virtual Humans, bundled runtime assets, the multiplayer relay source and guide, and the Policy Panic showcase World. Unzip it and run the launcher for your platform; no installer is required.
