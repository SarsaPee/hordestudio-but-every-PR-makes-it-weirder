# Horde Studio 15.9.0

## Virtual Humans now live beyond the chat

- Added persistent lightweight social worlds for friends, family, coworkers, partners, exes, classmates, neighbors and acquaintances.
- Supporting people now maintain their own evolving closeness, trust and tension, influencing availability, mood, gossip and decisions without becoming extra chatbots.
- Expanded Active Life authoring so creators can define each supporting person's role, influence, contact rhythm, relationship state and knowledge of the player.

## Deterministic life simulation

- Schedules, sleep, work, travel, commitments, moods and supporting-cast contact now advance locally without calling an LLM every minute.
- Meaningful schedule and social transitions are recorded in a bounded simulation ledger for continuity.
- Expensive models remain focused on meaningful decisions and writing the final message or post.

## Smarter Tiny Brain assistance

- Added bounded local contact evaluation after the deterministic autonomy kernel finds a plausible reason to reach out.
- Added allowlisted memory relevance selection so the local model may retrieve existing memories but can never invent or rewrite them.
- Kept social-signal extraction, memory gating and continuity checks safely advisory: malformed, uncertain or unavailable Tiny Brain output falls back to the proven engine.

## Crash-safe autonomy

- Added a persistent always-on event queue that stores generated events and counters but never API credentials.
- Made always-on event imports transactional: events are acknowledged only after timeline state saves successfully.
- Added exponential provider backoff, bounded retries and a spending circuit breaker after repeated failures.
- Added a visible global **Pause agency** emergency control; direct user-requested replies remain available while background initiative stops.

## Autonomy Health

- Added an optional 2, 4 or 8 week fast-forward simulation for creators.
- Reports potential spam, schedule conflicts, impossible authored travel, repeated posts, relationship jumps, personality drift and projected model-call pressure.
- The report is advisory only and never changes, blocks or sanitizes the creator's character.

## Quality and verification

- Expanded Virtual Human, Labs cognition, always-on runtime, settings and contextual-help regression coverage.
- Verified the new Active Life and Autonomy Health interfaces in-browser at desktop and constrained layouts.
