# Horde Studio 15.9.2

## ComfyUI private-LAN support

- Fixed a validation mismatch that accepted private network addresses in Settings but rejected them inside the local bridge.
- ComfyUI and OpenAI-compatible image servers may now run on another computer on the same private network using addresses such as `http://192.168.1.42:8188`.
- Added clear setup guidance beside the ComfyUI address, including LAN listening and firewall requirements.
- Added contextual help for configuring a remote ComfyUI machine.
- Public internet endpoints, embedded credentials, query strings, fragments, multicast addresses and link-local metadata addresses remain blocked from the local-image bridge.
- Added regression coverage for IPv4 and IPv6 private networks and rejection of public or unsafe addresses.

Users hosting ComfyUI on another computer must enable LAN listening in ComfyUI and permit its port through that computer's firewall.

## Verification

- All 15 local bridge regression tests pass.
- Python bridge compilation, JavaScript syntax validation and whitespace checks pass.
