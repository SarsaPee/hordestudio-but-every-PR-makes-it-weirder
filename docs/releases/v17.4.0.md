# Horde Studio 17.4.0

This release connects Virtual Human daily life, conversations and photos more closely, and strengthens World simulation and persistence.

## Virtual Humans

- Shared browser and background simulation for activities, attention, recovery and delayed replies, with persistent goals and follow-through.
- Per-chat player profiles and durable player facts, plus stronger conversation grounding, relationship evidence and configurable texting styles.
- Short answers can remain short. Private thought/channel markers and tool receipts are filtered from visible replies.
- Configurable first-contact scenarios and optional periodic supporting-person planning for delayed messages and public comments.
- Dynamic closet items, simulated gifts and cash, and a redesigned gift dialog with photo cards, delivery modes and permission guidance.
- Recurring places, Google Maps and openrouteservice settings, route-based travel and persistent journeys.

## Photos and references

- Capture-time continuity snapshots and serialized photo generation. Eligible follow-ups combine the base identity image, previous photo, room and garment references.
- Fixed room roles and references linked to saved locations, with persistent removal and relinking.
- Personal photo direction and personality-aware prompts; reference-aware identity handling and explicit adult age.
- Improved Magnific/Higgsfield MCP model discovery, reference mapping/upload and image-result import.
- Starter photo batches finish importing and clear their progress state correctly.
- Optional OpenRouter vision tagging alongside local garment vision models.

## Worlds and reliability

- Stronger state transactions, reload persistence, directed travel, exit handling and background proposal validation.
- Regression coverage for browser storage, World movement, VH attention, social actions, photo continuity and background-host ownership.
- Release packaging is gated by engine and browser checks and includes the shared simulation modules.

## Updating

Extract the portable ZIP and launch Horde Studio using the launcher for your platform. Restart the launcher/bridge and reload the webpage to load the updated frontend and background host. Export a backup of your existing library before migrating installations; browser data belongs to its local origin.

Supporting-person LLM planning is optional and disabled by default. Enabling cloud providers uses their API credentials and may incur provider charges. Gift money and deliveries are simulated.

Verification uses synthetic data and mocked providers. Real model conversation quality and exact generated-image fidelity vary by provider and were not evaluated with paid calls for this release.
