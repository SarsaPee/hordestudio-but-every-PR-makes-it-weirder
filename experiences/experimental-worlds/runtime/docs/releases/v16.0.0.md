# Horde Studio 16.0.0

Horde Studio 16 is the **World Creator overhaul**: large settings are now easier to author, older worlds can be upgraded safely, and the runtime treats roles, knowledge, consequences and off-screen activity as first-class simulation state.

## A world studio built for scale

- Replaced long walls of location and entity fields with searchable cards, focused editors and clearer hierarchy.
- Separated people, groups and items into dedicated creator views.
- Added regions, nested places, buildings and rooms with stable IDs so edits keep their connections.
- Added flexible transit links for roads, paths, trains, ships, horses, dragons or fully custom travel.
- Improved location summaries, parent/child navigation and room creation inside the place that owns them.

## Legacy-world migration

- Added a schema-v4 migration pipeline for older and imported worlds.
- Added creator-facing health checks that find missing roles, invalid containment, broken links, legacy entity shapes and incomplete simulation data.
- Migration previews are non-destructive and can be reviewed before applying.
- Bundled worlds now normalize into the current region, location, entity and rules structures.

## Persona-driven RPG play

- Worlds may define their own skills, perks and flaws without bloating the global persona.
- New sessions snapshot the selected persona, public identity, reputation and world-specific capabilities.
- Checks now use the world's rules, capability modifiers and progression state.
- RPG rules remain optional: creators can use automatic checks, manual dice or no mechanics at all.

## Transactional world engine

- Turn updates now validate and commit as one authoritative state transaction.
- NPC knowledge tracks source, confidence, visibility and provenance instead of granting everyone omniscience.
- Consequences have explicit creation, escalation and resolution lifecycles.
- Deterministic background simulation advances eligible NPC agendas without paying for a model call every tick.
- Autonomy Health can rapidly audit impossible travel, repetition, drift, abrupt relationship changes and runaway activity before a world is shared.

## Reliability and Virtual Human fixes

- Strengthened malformed-output and tool-leak cleanup so internal state instructions stay out of chat.
- Improved thinking-model timeout handling and response-length enforcement.
- Consolidated Ashlyn's bundled photos and clips under one portable media root and retained compatibility with older asset paths.
- Expanded regression coverage across schema migration, world roles, consequences, movement, gameplay, authored worlds, calibration and Virtual Human archives.
