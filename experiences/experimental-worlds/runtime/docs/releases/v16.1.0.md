# Horde Studio 16.1.0

Horde Studio 16.1 is a reliability and local-cognition release. It introduces **TinyBrain 2**, makes Pip a useful command center, guarantees the advertised built-in Virtual Humans are present in the portable app, protects authored worlds from silent loss, and finally gives the local server a deliberate shutdown path.

## TinyBrain 2 and Horde Labs

- Added TinyBrain 2, powered by the Apache-2.0 Cactus Needle 2 structured router.
- Added a small browser-cached WASM runtime for bounded tool selection, argument extraction and local request routing.
- Added confidence gating and deterministic validation: grammar-valid output never bypasses Horde Studio's state checks.
- Retained TinyBrain 1 as a legacy compatibility option and connected local models for generative background tasks.
- Added runtime loading guards and actionable errors for incomplete or stale portable copies.
- Added task-aware availability so Needle is used only where its structured capabilities are appropriate.

## Pip command center

- Rebuilt Pip as a searchable Horde Studio help and diagnostics workspace.
- Added grounded handbook answers, provider diagnosis, Labs diagnosis and direct navigation actions.
- TinyBrain 2 can route Pip requests privately while product facts still come from Horde Studio's versioned handbook.
- Added clearer runtime status, quick-help topics and response actions.

## Built-in Virtual Humans that are actually built in

- Ashlyn “Ash” Reynolds and Jane Harlow are now embedded directly into the portable application's core HTML during packaging.
- Fresh or accidentally emptied human libraries automatically restore every available built-in.
- Added release-time validation so a missing or malformed built-in fails the portable build instead of shipping an empty advertised library.
- Bundled media remains normalized under the portable asset tree.

## World and creator recovery

- Fixed the World Studio **New Person** buttons passing a browser click event as an entity type.
- Invalid legacy worlds are preserved with a visible repair warning instead of being silently filtered and lost.
- Added bounded recovery snapshots when a world unexpectedly disappears from a later save.
- Reimporting an orphaned world can reconnect its existing sessions, state and media.
- Expanded creator and included-human audits for the new recovery paths.

## Local runtime lifecycle

- Added a loopback-only **Stop Horde Studio server** control under Settings → Local Runtime.
- Stopping the server also stops background Virtual Human agency without deleting saves, settings or downloaded model caches.
- Ctrl+C and normal termination now close runtime resources consistently.
- A launcher no longer mistakes an older release or another extracted copy on port 43127 for the current app; it selects a free local port and keeps bridge URLs aligned.
- Health checks now identify the running build and application instance.

## Portable and licensing improvements

- Added TinyBrain 2 runtime files and third-party notices to the portable archive.
- Updated the portable builder to embed the two advertised humans and fail loudly when their definitions are missing.
- Refreshed the Horde Labs architecture documentation for the three supported local-cognition paths.

## Verification

- JavaScript syntax checks pass.
- Python bridge compilation passes.
- Git whitespace validation passes.
- TinyBrain 2 installation was exercised in a clean local browser session.
- The shutdown endpoint was exercised against an isolated server and exited cleanly with code 0.
- The portable archive is rebuilt from the tagged source and inspected before publishing.
