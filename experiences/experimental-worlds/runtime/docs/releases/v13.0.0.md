# Horde Studio 13.0.0

Horde Studio 13 is the Virtual Human release: people now carry a deeper, persistent emotional architecture, human pressures that affect behavior, and two fully authored showcase lives. It also strengthens local-provider workflows, settings reliability, and imported character fidelity.

## Virtual Humans with emotional continuity

- Added a Plutchik-inspired eight-channel emotion state: joy, trust, fear, surprise, sadness, disgust, anger and anticipation can coexist instead of collapsing into one mood label.
- Events are appraised by impact, threat, loss, novelty, control, social safety, norm violation and responsibility before emotional state changes.
- General feelings and player-directed feelings are tracked separately, preventing unrelated bad days from automatically becoming resentment toward the user.
- Added authored emotional sensitivity, visible expression, rumination, reaction timing and emotional-complexity controls.
- Humans can mask feelings, process a reaction later, remain angry through a genuine cool-off period, or gradually repair after conflict.
- Energy, stress, social need, inhibition and contextual intoxication now evolve inside each timeline and can affect response timing, initiative and tone.
- Silence and ghosting feed the same emotional system, so concern, hurt and detachment develop from elapsed time without requiring extra model calls.

## Optional adult desire simulation

- Added an explicitly opt-in system for adults that models baseline libido, spontaneous versus responsive desire, confidence, risk appetite, frustration, cooldown and post-intimacy aftereffects.
- Libido, attraction, trust and consent remain mechanically separate. High desire cannot manufacture attraction or override authored boundaries.
- Intimacy initiative remains subject to ordinary autonomy controls, unanswered-message limits, media permissions and creator-authored limits.
- Existing humans remain opted out unless a creator deliberately enables the feature with an explicit adult age.

## Two complete included humans

- Bundled Jane Harlow and Ashlyn “Ash” Reynolds as fully authored Virtual Humans available to fresh and existing installations.
- Both include profile and generation-reference images, detailed psychology, relationship context, locations, recurring people, wardrobes, weekly schedules and wildcard events.
- Included humans are offered once. Deleting one is respected and will not silently restore it on every launch.
- Bundled character data contains no creator chat history, learned memories or lived timeline state.

## Better local and modular providers

- Added a configurable idle timeout for local World generation; active streaming resets the timer and creators can disable the timeout.
- Embeddings can use a separate OpenAI-compatible server, model and API key without changing the active text provider.
- Virtual Humans can use a dedicated local OpenAI-compatible neural TTS endpoint while text and images remain on other providers.
- Added connection tests and contextual help for the new local generation, embedding and speech controls.

## Settings and data reliability

- Added a small credential-free local settings mirror that can recover ordinary preferences when a browser IndexedDB transaction is evicted or interrupted.
- Settings now use a dedicated persistence transaction and timestamped recovery rules.
- Credentials and heavyweight ComfyUI workflow JSON are excluded from the recovery mirror and normal exports.

## Character import fidelity

- Preserved SillyTavern creator notes, source metadata, tags, alternate greetings and supported depth prompts.
- Alternate greetings become selectable message versions instead of being discarded.
- Imported depth prompts are placed at their intended conversational depth.
