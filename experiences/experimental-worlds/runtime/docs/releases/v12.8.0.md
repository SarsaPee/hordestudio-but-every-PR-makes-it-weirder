# Horde Studio 12.8.0

Version 12.8 makes the growing provider surface substantially easier to navigate, fixes Virtual Human creation at the data-model level, and incorporates the latest community contributions without overriding creators' choices.

## Virtual Human creation integrity

- Every new Virtual Human now receives a collision-resistant identity instead of reusing the name-derived `companion_new_virtual_human` ID.
- New Human Studio sessions clear previous builder notes, generated previews, test prompts, voice previews and pending upload selections.
- Existing libraries are repaired automatically when duplicate Virtual Human IDs are detected.
- The first repaired record keeps its existing timeline; duplicates become independent humans with clean timelines so saving or deleting one cannot affect another.
- Added dedicated regression coverage for new creation, duplicate migration and transient form cleanup.

## Redesigned Settings

- Rebuilt Settings as a navigable modal with a persistent section sidebar.
- Organized the full configuration surface into AI & Models, Connections, Images & Workflows, Behavior & Output, Memory, Editor Appearance, Local Runtime, and Data & Backup.
- Added settings search with `Cmd/Ctrl + K`, live matching, keyboard dismissal and retained contextual footer actions.
- Added responsive tablet and phone layouts while keeping all existing controls and provider options available.

## Provider and starter-model reliability

- Bundled Worlds and the starter Chat character now inherit the selected global model instead of pinning OpenRouter or DeepSeek defaults.
- New Worlds remain unpinned until a creator deliberately chooses a World-specific model.
- The migration is restricted to exact bundled IDs and exact legacy model values; authored characters and Worlds are never globally sanitized.
- Fixed a Labs local-server discovery syntax error found while consolidating the network contribution.

## Community contributions

- Added SillyTavern V2/V3 card-envelope unwrapping and PNG character-card import support.
- Added configurable local/LAN bridge listening through `.env` settings and portable launchers.
- Expanded the connection policy and bridge routing for local-network model servers while preserving browser security boundaries.
- Removed provider-specific model pins from the bundled starter templates.

## Validation

- JavaScript syntax checks pass for every shipped source file.
- The complete Horde Studio audit suite passes, including Virtual Humans, Worlds, movement, Labs, providers, security, media, responsive UX and import/export coverage.
- The portable 12.8 package is built from the same tagged source used by the application.
