# Horde Studio 16.7 Sidecar integration manifest

Apply these hooks to a clean upstream 16.7.0 checkout in feature-sized commits.
Do not copy `app.js`, `index.html`, or `style.css` into this bundle.

## Required load order

Load `runtime/mode-config.js`, then `integrations/horde-16.7-hooks.js`, before
the application script. Validate that `window.HordeSidecarMode` and
`window.HordeSidecarHooks` exist before a World session is created.

## Native canonical seam

The only Sidecar write path is:

```text
validateWorldTurnReceipt → commitWorldTurnReceipt → processStructuredActions
```

At the 16.7 integration point, branch `executeWorldTurn` after session
normalization. In Sidecar mode, disable narrator tools and all Legacy receipt
repair/classifier fallbacks, stream the narrator handoff without displaying it,
then call the native commit tool exactly once from the Sidecar model.

## Required app hook groups

1. **World/session normalization:** validate and normalize `sidecarConfig` and
   `timeline.sidecar`; new worlds default to Sidecar, existing worlds to Inline
   Legacy.
2. **Turn dispatch:** bypass Legacy automatic movement, turn ticks, schedule
   sync, World Agent, quest evaluation and repair paths in Sidecar mode.
3. **Reducer adapter:** pass Sidecar source metadata into the native commit
   seam, preventing Legacy narrated-presence recovery and population/schedule
   mutations from becoming Sidecar state.
4. **Prompt/UI:** add the narrator handoff contract, next-turn packet,
   staged generation labels, Backstage cards and per-world trace retention.
5. **Direct Sidecar mode:** keep its conversation records in
   `timeline.sidecar.conversations`, never in normal roleplay history. Route
   explicit refinements through the same receipt validator/reducer.
6. **Time:** preserve `ANSWER core.time` verbatim in
   `timeline.sidecar.temporalState`; the existing reducer clock is only the
   mechanical representation.
7. **Configuration:** add Sidecar mode/tracker/debug/routing controls to World
   Studio. The Sidecar routing scope falls back to world then global routing.

## Current intentional limits

This manifest does not yet provide the complete migration wizard, Sequence /
Scene UI, progressive promotion, vehicle adapters, memory worker graph, or
proposal-only World Agent. Keep each as a subsequent isolated PR.
