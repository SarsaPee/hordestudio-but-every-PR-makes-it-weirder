# Legacy to Sidecar migration contract

Migration is selected-world, user-triggered and reversible. It must create a
backup, run a compatibility scan, retain canonical source history and discard
only derived vector caches/embeddings for rebuild. Legacy worlds remain Inline
Legacy until the user explicitly approves Sidecar conversion.

The initial foundation only normalizes the protocol envelope. It does not
advance time, reinterpret history, convert relationships, promote locations or
change canonical world state.
